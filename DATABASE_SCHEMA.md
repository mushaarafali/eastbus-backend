# EastBus database tables

`users` — admin/operator/passenger identities  
`operators` — operator/company profiles and approval state  
`buses` — operator fleet  
`seats` — seat configuration per bus  
`staff` — operator-created driver/conductor accounts  
`routes` — operator routes  
`route_stops` — authorised boarding/drop-off stops  
`trips` — scheduled starting/return turns and assignments  
`bookings` — passenger booking records  
`payments` — transaction metadata only  
`notifications` — announcements and operator notices  
`live_locations` — GPS samples for active trips  
`emergency_alerts` — staff emergency alerts  
`system_logs` — admin/operator audit events
